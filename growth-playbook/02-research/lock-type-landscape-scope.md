## 1. 全球民用锁型家族地图

| 锁型家族 | 主要地区 | 占当地住宅粗估 | retrofit 可改造性 | 现有对手 | v1 覆盖? |
|---|---|---|---|---|---|
| **A. 美式单舌呆锁(single-cylinder deadbolt,内侧 thumb-turn)** | 北美 | ~60–70% 独户/公寓 | ★★★ 最成熟:内侧替换/包裹 | August、SwitchBot、Level(内嵌式) | ✅ **首发唯一打击面** |
| B. 双边钥匙呆锁(double-cylinder) | 北美(带玻璃门) | ~5% | ★ 内侧无旋钮,且消防法规敏感 | 基本无人做 | ❌ 排除(法规风险) |
| C. 美式 mortise 锁体 | 美国东北老公寓 | ~8–10% | ★ 结构碎片 | 少 | ❌ |
| D. RIM / Night latch(夜锁,NYC 极多) | 美国东岸/英国 | NYC ~20%+ | ★★ 可行(旋钮在壳上) | 小众(Tedee 无、少数贴牌) | ⏳ v2 观察位 |
| E. **欧标锁芯(euro profile, DIN 18252)含内侧旋钮款** | 欧洲大陆 | ~50%+ | ★★★ Nuki/Tedee 已验证 | Nuki、Tedee、SwitchBot(日本亦适配) | ⏳ v2(众筹 $600k 拉伸目标立项) |
| F. 英/美 multipoint(uPVC/复合门,提把手上锁) | 英国/欧陆新楼 | 英国 ~25% | ★ 把手联动,retrofit 难度高 | Yale Linus 部分、少有 | ❌ v3 再说 |
| G. 英国 mortise sashlock(BS3621 5-lever) | 英国老房 | ~20% | ★ | 少 | ❌ |
| H. 执手连体锁(interconnected,加州等消防要求常配) | 美国西岸公寓 | 可观 | ★ 上锁与下把手联动 | 少 | ❌ 排除(法规+结构) |
| I. 中式 6068 锁体(插芯) | 中国/东南亚 | 主导 | ★ 市场默认整锁替换 | 小米/Aqara/德施曼生态 | ❌(亚太非首发区) |

**首发打击面 = 家族 A。** 理由:① 单锁型覆盖北美最大可服务人群 ② 结构与 August/SwitchBot 完全同构,OEM 成熟、风险最低 ③ 与 [iot-gtm §6](../01-foundations/iot-gtm-methodology.md) 的北美先行策略自洽。

## 2. 家族 A 内部变体与适配件策略(工程清单)

拇指旋钮(thumb-turn)碎裂是这个家族唯一的坑。v1 锁体 = "**电机扭矩座 + 多适配片**"(August/SwitchBot 同款思路),需实测量产以下适配片:

| 适配要素 | 范围要求(冻结前实测确认) | 备注 |
|---|---|---|
| 旋钮形状 | 长腰形(oval)/ 圆形 / 条形(bar) | 3 套适配片起 |
| 旋钮轴径 | 5–8 mm | |
| 尾部行程(throw) | ≥180° 回转容忍 | 电机行程需冗余 |
| 面板到旋钮净空 | 适配片高度 8–15 mm 阶梯 | |
| 门厚 | 35–60 mm(锁体本身不跨门,仅确认旋钮外露) | |
| 背胶/机械双固定 | 背胶为主 + 可选螺丝盘(to metal 面板) | 租客"无痕"承诺依赖背胶洁净剥离(3M VHB + 除胶剂配套) |
| 钥匙自转检测 | 有(外部钥匙转动 → 内侧旋钮动 → 锁体检测并同步状态) | "老钥匙仍可用"承诺的技术前提 |

**首发测试门矩阵(工程验收 30 门)**:AB/Schlage/Kwikset 三大美标呆锁各×常见旋钮形状×门厚两端值 + 10 扇真实北美公寓门(旧金山/纽约老公寓重点,面板小、净空紧的最坏情况)。

## 3. 扫描器 AI 分类体系(v1)

| 项 | 冻结定义 |
|---|---|
| 输入 | 2 张照片(正视角内侧旋钮 + 门外锁面) + 1 张侧向门边(锁舌面) |
| v1 类目(图像分类) | A 单舌呆锁-腰形钮 / A 单舌呆锁-圆钮 / A 单舌呆锁-条钮 / B 双钥匙呆锁 / D Rim 夜锁 / E 欧标旋钮锁芯 / E′ 欧标双钥匙锁芯 / F 提把手多点锁 / G 其它-可判断 / Z 其它-不可判断 |
| 置信度策略 | ≥0.9 直接出报告;0.6–0.9 "人工复核 12h 内"(上线初期=运营人工,后接 MLOps);<0.6 引导补拍 |
| 报告输出 | 锁型 + A 家族判定(✅/❌/v2 支持预告)+ 难度(免工具/建议协助)+ 下一步 CTA |
| 数据采集 | 每张图+分类结果入数据池(用户授权条款内)→ 反哺 [SEO 数据回路](../05-system/accessx-complete-growth-system.md) §6-5 |

v1 发布时 Z 类目标占比 <15%;每降 1pp,Z 类被重分入新类,类目表季度扩容(首扩:D/E)。

## 4. 给工程的输入清单(handoff)

- [ ] 本文件 §2 适配片组 + 30 门测试矩阵 → 结构工程 2 周内回签可行/不可行
- [ ] 扭矩与噪音目标:开关全行程 ≤8s,夜间模式 ≤45dB(邻居投诉红线)
- [ ] 电池:4×AA ≥10 个月(日均 10 次行程) + USB-C 应急供电口(锁外底部)
- [ ] 离线自治:断网 BLE 全功能;云端仅做日志/客人码分发(对齐"永不远程变砖"军规)
- [ ] 认证:FCC + BHMA 3 级起步;欧标版才启 CE
- [ ] BOM 红线:≤$38([bundle-software-to-hardware.md](../03-design/bundle-software-to-hardware.md) §2 经济模型)

## 5. 范围外声明(写清楚不做什么)

- ❌ 不做可视门铃/摄像头一体机(隐私定位冲突+红海)
- ❌ v1 不做键盘(keypad)内置;外置蓝牙键盘作为配件拉伸目标
- ❌ 不支持 double-cylinder 与 interconnected(法规风险,报告页要明确解释给这类用户替代建议)
- ❌ 不做 Apple Home Key 级门禁卡首发(NFC 生态排期 v2,先看扫描数据中 iPhone 占比)
