# 下一单验证包：从研究转向证据，而非继续扩题

2026-09-28。全部计划尚未执行；没有新增预算、外联、开户或实机测试授权。本轮只准备离线决策工具，后续所需人工/外部输入不伪装为已经完成。

## 1. 一句话要验证什么

> 一个已有真实Host/商业客户的软件伙伴，是否愿意为一套明确适配的TTLock硬件，按中国预付款条件采购，并与我们清楚划分安装、软件、支持和应急职责？

次级验证：同一个业务问题是否值得独立软件/服务收费。不要把采购硬件的兴趣同时算成付费软件需求。

选定一个SKU配置、一个目标国家、一个终端工作流。第二国家最多做备选。Troublemaker柜子若要求完全不同机械SKU，另立候选，不与家门方案共享“已验证”状态。

## 2. 四条候选路线，只有一条进入付费试点准备

|路线|需要的外部证据|进入理由|不进入理由|
|---|---|---|---|
|R1 直接TTLock的软件伙伴|真实客户、SKU、实际接口权限与成本、预付款接受度|匹配单生态主线|要账期/无应急/不适配/无客户|
|R2 已有Seam的软件伙伴|R1基础＋现有Seam合同范围、计费主体、SKU能力|伙伴可能已有连接能力，我们补交付|需要我方包终身平台、转售授权不清、只是试AI|
|R3 Troublemaker会员柜|需求归属、柜体尺寸、事件账本、预算与责任人|当前唯一用户转述的具体柜子线索|需求属于第三方且无法确认、原锁不适配、管理节省不足|
|R4 独立仓储运营者/软件商|一类单元门结构、入口独立、安全取物、采购预算|经营痛点潜在明确|专业大改造、无应急、必须改造整个系统|

排序是当前策略，不是调研评分。R1没有证据时不自动算合格，R3有预算/适配证据时也可能先进入。保持其他生态执行暂停。

## 3. 七项硬门槛：任何一项失败都不能靠高分弥补

|Gate|准入要求|必须留下的证据|
|---|---|---|
|G1 合法授权|买方/场地有权采购、安装、配置，数据授权成立|角色、授权范围、许可记录；不上传多余个人资料|
|G2 机械与完整套装|具体型号/固件/配件和一种目标门型匹配|尺寸、合法照片、供应商规格、网关/键盘需求；实机验证另阶段|
|G3 基本访问与应急|故障/停订阅/网络问题有合法安全恢复方案|现场责任角色和待演练步骤；未经演练不得称通过|
|G4 付款条件|订金后排产、余额清算后发货，无寄售/应收账期|买方书面接受；研究阶段不是订单|
|G5 全成本贡献|按同一套装、所有必需费用和支持责任核算|实际供应报价、费用和敏感度；未知关键成本不可填0|
|G6 技术与平台边界|TTLock/可选Seam权限、费用、区域、能力、撤权限制明确|官方/合同资料＋必要实测；SDK存在不等于资格通过|
|G7 可重复需求|实际近期场景，预算负责人，范围可限定|最近30天事件账本、完整价格反馈、可复用边界|

P0阶段允许标记“资料齐备待测试”；只有之后获得授权、完成所需测试才能标记技术/安全通过。不得为了推进把供应商自述当我方验收。

## 4. 硬门槛后才打分（当前全部留空）

每项0–5，换算为权重×分数/5，总分100。资料未知就不评分，不能用中间分代填。

|维度|权重|5分的例子|0分的例子|
|---|---:|---|---|
|问题频率/经济价值|25|有去标识事件记录，完整成本后有明确价值|无痛点或原工具足够|
|预算与预付证据|20|预算拥有者书面确认具体范围和付款原则|无购买计划/只能账期|
|标准化复用|20|同一配置有第二独立客户需求证据|每门/每客户重做|
|支持负担|15|试点数据支持明确低支持工时和本地责任|责任空缺/无限支持|
|渠道带量证据|10|已有类似产品重复成交和可核实客户需求|仅社群规模或下载量|
|投入与集中风险|10|有限前置投入、多方可替代、退出可控|押注一家/高定制/不可回收费用|

建议阈值：≥75且全部关键门槛具备阶段所需证据，才申请有限试点；60–74补证；<60不优先。阈值是管理提案，不是统计预测。不得把无真实测试的“低支持负担”打5分。

## 6. 一单经济核算卡：消除旧模型混用

### 我方硬件

净确认收入 = 约定净硬件销售额 − 折扣 − 预计退款/退货抵减。

直接成本 = 工厂完整BOM＋必需配件/网关分摊＋包装/质检＋我方承担运输/手续费＋直接支持工时×费率＋预计保修/退货处理＋依法由我方承担的其他成本。

订单贡献 = 净收入 − 直接成本 − 该单独立设置/交付成本。

如果网关共享，必须有覆盖/容量证据才可按小于1台分摊。退货抵减与退货净成本要按同一口径处理，避免把同一损失重复计两次或漏算。

### 平台/软件/渠道各自一张表

- 谁签Seam/TTLock/现有PMS合同，谁按月付费？未知不能填0。
- 我方软件收入只算独立功能和我方履约，不含客户直接付给第三方的钱。
- 同一订单渠道折扣与引荐佣金若叠加，必须明确重新计算；不双重归因。
- 终端TCO包含实际进口、安装、平台、维修等，不能拿我方出厂价冒充终端总成本。

### 现金时间轴

日期/事件：设置费用→客户订金到账→供应商分期款→质检→客户尾款清算→发货→合同验收/收入确认→保修/退款。

逐事件累计现金，不仅看月末。客户订金为负债；预算安全缓冲不是利润。包括延迟一个采购周期、支持工时翻倍、可变成本+20%、订单量减半四个压力情景；没有报价前只保留公式，不算精确资金需求。

## 8. 停止条件和回退路径

- 3次合格访谈后，没有人提供实际问题或完整价格预算：停止该场景，不扩大名单掩盖转化差。
- 一周资料收集仍无法识别SKU/网关/应急前置条件：保持研究状态，不进入预售。
- 任何未授权访问、无法安全取物或严重数据泄露：停止测试路径，恢复安全替代并调查；小样本无事故不等于证明无风险。
- 支持工时翻倍即负贡献：缩范围/重新报价，不靠未来规模“摊掉”每单可变亏损。
- 买方要求账期、寄售、欧洲独家或无限定制：不进入当前计划。
- Seam不适用：在合法权限与实际成本允许时考虑直接TTLock；不是自动切换或绕过合同，仍需验证。
- 柜体不适配：柜子方案停止或另立独立SKU资格验证，不说现有门锁可以勉强用。
