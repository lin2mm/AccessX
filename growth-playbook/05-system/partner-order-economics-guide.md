## 3. 标准示例：50套，而不是只算50个裸锁

### 我方出口供货账

| 项目 | 每套假设 |
|---|---:|
| 裸锁及出口前交付成本 | $50 |
| 键盘成本 | $18 |
| 网关成本（独立分散房源，每套一个） | $22 |
| 质保/基础服务/收款预留合计 | $11 |
| 新增L2支持15分钟，$30/小时 | $7.50 |
| 合计变量成本 | **$108.50** |
| 出口净销售价 | **$139** |
| 每套贡献 | **$30.50** |

$11沿用前模型变量成本假设；新增L2支持独立列示，不重复包含在其他项。网关/键盘的质量与支持成本若超出该预留须上调。

50套贡献$1,525，减一次性标准伙伴开通/资料支持成本$300，批次结余**$1,225**。这还没覆盖公司年度人员固定成本、研发/认证、税和资本成本，不能称净利润。

### 进口转售伙伴账

终端未税售价$179−采购139−进口/运费预算10−L1支持5−支付4−伙伴侧质保/本地RMA预算3 = **$18/套贡献**，50套=$900。伙伴自身获客和固定成本还没扣。伙伴$3针对本地责任，与我方出口质保预算分别承担，不把同一赔付双算。

### 终端第一年账

硬件购买$179＋自助设置时间成本$10＋假设第三方平台$6/月×12 = **$261/门/年**。

这里$6只用于敏感性示例，不是给所有候选平台统一定价，更不等于我方收入。零售价假定含伙伴预算内的进口与物流，不再向客户重复加$10运费。当地销售税/VAT、网络/电源额外费用、配件更换、客户内部培训、未包含的人工安装另算；不能声称完整税后TCO。若某平台要求强制网关或键盘，要按实际组合报价。

## 4. 七种情景的结果

| 情景 | 我方每套贡献 | 批次扣接入成本后的结余 | 批次现金桥接缺口 |
|---|---:|---:|---:|
| 50套标准套装，净价139 | $30.50 | **$1,225** | $1,325 |
| 同一套装仍卖旧裸锁价89 | -$19.50 | **-$1,275** | $2,575 |
| 50套，但专属集成花2,400 | $30.50 | **-$875** | $3,425 |
| 50套，共享网关比例0.2 | $48.10 | **$2,105** | $445 |
| 我方承担首年每门每月6平台费 | -$41.50 | **-$2,375** | $2,375 |
| 50套，每套L2支持升至60分钟 | $8.00 | **$100** | $1,325 |
| 20套标准套装 | $30.50 | **$310** | $710 |

共享网关情景只适用于空间位置/信号/吞吐/租户隔离/平台映射均实测满足条件的同场所；不能给分散公寓统一按一网关五把锁省成本。脚本对网关数量向上取整。零售价在敏感性中保持不变，仅为隔离变量，不证明市场接受。

**现金桥接算法：**先付开通成本→收50%预付款→支付全部硬件供应成本→收清尾款后放货→预留本情景全部变量/服务成本；跟踪过程最低点。单订单缺口不是全年融资需求，未计批次并发、公司固定成本、库存延误或额外退款缓冲，不能取代年度模型。

## 5. 可直接使用的接单纪律

- **低价不自动亏，配套不清才危险。**给完整套装报价时，必须把平台要求的必要配件一起算，不用裸锁价格引流后隐藏强制加购。
- **小单可以做，但不带免费专属研发。**标准50套例子为正，加入$2,400专属开发后为负。按$30.50每套贡献，约79套才能覆盖这笔开发，仍未覆盖公司固定成本；不是承诺79套一定回本。
- **不要默认替伙伴承担第三方订阅。**一次性毛利补贴经常费会快速变负。若要打包，明确期限、真实采购费、续费方与退出后基本访问，不承诺永久云服务。
- **支持工时是硬指标。**60分钟情景50套仅余$100，几乎没有风险空间。应优先减少安装误差、改善资料/筛选/诊断，而不是继续加渠道。
- **伙伴也要赚得到。**标准例伙伴每套只有$18，需要确认值得其推荐；不能只展示我方毛利。
- **先款后货不覆盖所有成本。**标准例买家50%预付$3,475，硬件全款成本$4,500，另有开通费，仍需现金桥接。

计算器的economic_candidate_only只表示所列经济条件尚可，不是认证、安全、资金或合作批准。任何适配/授权/逃生/合规硬门槛未过，经济再好也hold。

## 6. 软件独立业务不被硬件账混淆

| 终端组 | 报价/服务边界 |
|---|---|
| 家庭 | 免费基础访问与交接；无需商业自动化时不硬加平台月费；套装按所需功能选 |
| 租客/合租 | 先确认安装许可、付款人和设备归属，不能用预付款规避许可；无硬件也能用免费交接工具 |
| 短租经营者 | 完整自动化组合按第一年成本与交接工时评估；必须计入平台费与应急支持 |
| 长租物业/多点经营 | 分开普通单元门和公共门禁；不将此套装假设用于未经验证的公共出口 |

我方软件收费、伙伴软件收费、我方硬件收入分别记账。不将第三方平台费计入我方ARR，不将渠道进货等同终端净验收，不因我方SaaS欠费禁用基本通行。
