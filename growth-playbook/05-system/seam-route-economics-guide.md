# Seam还是直连TTLock：完整成本与承担方式

2026-09-28。金额USD，不含税。公开价来源：[Seam pricing](https://www.seam.co/pricing)，Unit Access $5/设备/月、5 actions/设备/日；High Traffic $50/设备/月、unlimited actions；500+设备可协商。报价、计费定义和实际功能适用性未确认。**不将示例成本当成TTLock免费政策、Seam折扣或我方真实交付能力。**

## 1. 三种商业路径

|路径|平台合同/费用|我方收入|优先级|
|---|---|---|---|
|直接TTLock|合作方或我方获得所需授权，自行承担实际费用、研发和维护|独立硬件、真实独立软件或交付服务|继续既有单生态优先路线|
|BYO Seam|软件伙伴自有Seam合同并付费；授权我方仅做约定服务|预付款硬件和独立交付/工作流，不含Seam平台费|优先评估；适合已用Seam的伙伴|
|我方采购并转售/捆绑|需核实集成/转售权利、主代理会计、预付周期和退出义务|只能按合法合同与实际履约核算|暂缓，先验证毛利与授权|

不向Seam收取假设佣金；不把Seam的客户列表视作我们的线索所有权；不提供我方万能共享API key。伙伴端PMS若已包括连接费，不能再向终端重复计同一项费用。

## 2. 列价预算，不是最终报价

固定平均设备量，全年12个月：20台Unit为$1200/年，100台$6000，500台$30000；High Traffic对应$12000、$60000、$300000。500+只是未获企业报价前的列价参考。

公共柜子每天大量物理开柜不一定等于大量计费actions；反过来权限签发/撤销/失败重试可能也计量。必须先确认定义才能选档，不能用“设备少所以很便宜”推断。免费页写Free trial，不得默认为永久免费、无卡生产或无限真机。

## 3. 36个月研发＋平台TCO示例

相同支持范围、合法权限和安全结果可比时才使用。两条路径共同的硬件、网关、网络、物理安装、进口税、现场应急、业务系统和常规业务维护成本不计入差额；若两条路径实际不同，须加入差额。忽略折现/FX，仅做预算敏感度。

纯假设输入：人工$40/小时；直连初始240小时、每月维护12小时；Seam初始60小时、每月维护4小时；直连上游费暂用$0作敏感度基线，**非已验证免费**；Seam $5/台/月；设备量36个月保持不变；不含额外付费支持。

|平均计费设备|直连36个月|Seam36个月|Seam相对节省|
|---:|---:|---:|---:|
|20|26880|11760|15120|
|100|26880|26160|720|
|500|26880|98160|-71280|
|2000|26880|368160|-341280|

500/2000台使用未谈判列价，不能拿表格宣称Seam大客户一定不划算。实际应按月计费设备求和，不拿年底规模乘36。

此组假设的36个月交叉点约104台：初始节省$7200＋36个月维护节省$11520，共$18720；每台36个月平台费$180；18720/180=104。**104不是行业规律，更不是产品推荐硬阈值。** 已有直连接口时历史开发费为沉没成本；已有Seam接口时也不能再次记一次完整Seam开发费。未来维护、迁移、安全验证与真实平台报价决定增量选择。

敏感度：

- 20台High Traffic：Seam36个月$44160，直连基线$26880；须先确认流量与功能等价。
- 100台额外Premium support $20k/年：Seam合计$86160。它是额外支持预算示例，是否叠加、同合同覆盖须确认；不能把本地工程维护和厂商SLA当完全替代。
- 100台直连平台费假设$1/台/月：直连$30480，Seam$26160。
- 直连只需100小时初始＋每月4小时：100台直连$9760，Seam$26160。
- Seam反而需要180小时初始＋每月10小时：100台Seam$39600，直连基线$26880。

这说明关键不是接口费单项，而是**客户已有什么、要解决几种系统、未来维护谁承担**。当前保持TTLock单生态，不为获得聚合收益主动增加其他硬件生态范围。

## 4. 不要用一次性硬件贡献承诺永久免费API

此前套装模型单台贡献$30.5只是规划假设。若由我方持续承担Seam $5/台/月，约6.1个月就耗完该贡献；High Traffic $50一个月就超过。此前$49/月工作区示例若包含10个$5计费设备，仅上游已$50，尚未算支持/云费用就负贡献。

因此此前AI Builder运维价格、人民币规模模型、Host低价档都**不应被理解为已经包含Seam费用**。需要客户自付、明确另计、取得有效量价，或选择实际成本可行的直连路径；不修改旧模型中的未知价格来伪造盈利。

## 5. 我方可选工作流的单端点贡献示例

假设我方自身基础设施$0.75/端点/月、直接支持$0.50；均未验证。不含固定团队、获客、支付、税、退款、事故、资金占用。

|我方月收费|我方承担Seam|直接成本后贡献|状态|
|---:|---:|---:|---|
|$3|$5|-$3.25|不可行；且转售权未确认|
|$8|$5|$1.75|薄余量，未证明可覆盖固定费|
|$12|$5|$5.75|仍需真实客户愿付及授权|
|$12|$50|-$39.25|高流量不可用此价捆绑|
|$3，仅独立工作流|$0，我方不承担|$1.75|BYO Seam，客户另付其平台费|

BYO不代表客户总价只有$3：若其Seam实现价$5，则两者合计$8，还须加原PMS、硬件和当地服务。只有独立增量工作流才收费，不能对已含功能再次计价。

家庭/租客：基本访问免费计划不承诺免费提供持续付费上游。Host：比较真实每月交接/异常节省。商业运营：分柜子、入口、仓储单元门，分别确认动作计量和完全成本。四类不混算转化率。

## 6. 安全与账期是前置条件，不是经济性通过就能上线

硬件始终订金排产、余额清算后发货；与软件商签约和付款的链路不能因为Seam标准条款出现发票付款而改变。软件与服务如预付也按履约确认，已到账不全是利润。

平台停订阅/断网/账号撤销时，基本合法访问应由经过测试的本地凭据或现场应急保障；不保证所有云功能继续存在。不做“为追回欠费把门锁住”的自动化，也不根据平台API成功就把门视为安全。
