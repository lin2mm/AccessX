Access rules

Issue passcode

Codes go through the same policy engine as remote unlocks. The system tells you honestly whether the lock itself can enforce the rule.
TTLock voids a code that is not used within 24 h of its start — so start it on the day they first come in.

Register a visitor

The visitor gets a code for each door, valid only for the visit — the lock itself ends it, even offline. Codes run on whole hours (a TTLock rule). Sensitive doors are not offered: those need a rule and a second operator's approval.
Give one address — email or mobile. The link can be forwarded, but the code is only ever sent to that address. At a site with sensitive doors, registrations wait for your approval below.

Invitations

Links expire at the end of the invited window. Each link works once; approving sends the code to the invited address — nobody sees it here.

Visitors

Checking out ends the codes now (doors with a gateway). A door without a gateway keeps accepting the code until the end time unless it is removed at the lock. Visitor details are erased automatically after the retention period.
